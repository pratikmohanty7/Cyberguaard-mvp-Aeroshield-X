# CyberGuard — Institutional Digital Trust & Cyber Defence

CyberGuard is a cybersecurity platform prototype designed to explore how digital tools can support institutional security monitoring, threat analysis, and digital trust.

## Key Features
- Cybersecurity-focused dashboard and user interface
- AI-assisted analysis capabilities, where configured
- Security-related information presented through an interactive interface
- Environment-based API configuration
- Web application architecture suitable for further development

## Technology Stack
- Frontend: Web technologies used in the project
- Backend: Node.js and Express
- AI integration: Google Gemini API
- Deployment: Render-compatible configuration

## Getting Started
1. Clone or download this repository.
2. Install the required dependencies using `npm install`.
3. Create a local `.env` file using `.env.example` as a reference.
4. Add your own API key to the appropriate environment variable.
5. Start the application using the scripts defined in `package.json`.

## Important Notes
This repository contains a prototype intended for demonstration and further development. AI-generated results and simulated data should not be treated as verified security findings. Never commit API keys, passwords, or other secrets.
